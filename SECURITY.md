# Security Policy

## Reporting a vulnerability
Please do not publish customer data, database files, phone numbers, credentials, signing keys, or exploitable details in public issues. Contact the maintainer privately through the repository owner's GitHub profile and include reproduction steps with test data only.

## Supported versions
Security support applies to the latest maintained release only. This policy does not claim that any current build has passed a formal security audit.

## Data safety
DokanMate can contain customer/supplier contact details, invoices, balances, and business financial records. Users should keep an independent backup and protect their Android device. Do not use real customer records when filing bug reports.

## Release standard
Production releases should follow the checklist in PRODUCTION_HARDENING.md and the OWASP Mobile Application Security Verification Standard (MASVS).
